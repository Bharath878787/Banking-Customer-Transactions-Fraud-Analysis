# Banking-Customer-Transactions-Fraud-Analysis
End-to-end data analytics project using Excel, Python (Pandas), SQL, and Power BI to clean, analyze, and visualize banking transaction data for fraud detection and business insights.

🏦 Banking Customer Transactions & Fraud Analysis
📌 Project Overview

This project presents an end-to-end Data Analytics solution for analyzing banking transactions and identifying fraud patterns. The dataset was obtained from a publicly available online source and contained various data quality issues, including duplicate records, inconsistent values, text-formatted dates, and formatting irregularities.

The data was cleaned and validated using Excel, Python (Pandas), and SQL, followed by interactive dashboard development in Power BI to uncover fraud trends, customer behavior, transaction risks, and business insights.

The objective of this project is to help financial institutions understand fraudulent activities, identify high-risk areas, and support data-driven fraud prevention strategies.

🎯 Problem Statement

Banks process thousands of transactions daily across multiple channels such as ATM, Mobile Banking, Internet Banking, POS, and Branch Banking. Fraudulent transactions not only result in financial losses but also affect customer trust and operational efficiency.

This project aims to analyze banking transaction data to:

Detect fraud patterns and trends
Identify high-risk transaction channels and locations
Understand fraud behavior across customer segments
Provide actionable recommendations to reduce fraud risks
Support data-driven decision-making for fraud prevention

📈 Key Insights
Fraud Overview
Fraud Rate recorded at 41.91%
Total Fraudulent Transactions reached 3,564
Total Fraudulent Amount exceeded 22.97 Million

Customer Analysis
Male and Female customers showed similar fraud counts
Customers aged 21–60 years recorded the highest number of fraudulent transactions

Channel Analysis
Phone Banking recorded the highest fraud rate
ATM Channel recorded the highest number of fraudulent transactions

Transaction Analysis
RTGS and Cash Withdrawal transactions were the most targeted transaction types
43.52% of fraudulent transactions were marked with a successful transaction status

Geographic Analysis
Kolkata recorded the highest number of fraudulent transactions
Civil Lines Branch had the highest fraud count

Merchant Analysis
The "Other" merchant category recorded the highest number of fraudulent transactions (2,955)

Category Analysis
Salary-related transactions recorded the highest fraud count among all transaction categories

Trend Analysis
2024 recorded the highest fraud activity
2025 showed a decline in fraud transactions compared to previous years

Introduce stricter validation procedures for salary-related transactions.
